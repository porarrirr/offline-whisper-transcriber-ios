Xcode 27 を使用する前提で、指摘17（旧Xcodeとの互換性）は対象外とした。

| 指摘 | 修正内容 |
| --- | --- |
| 1 | Whisper進捗コールバックの所有メモリを `initialize` / `deinitialize` / `deallocate` で管理。成功・エラーの両方で捕捉オブジェクトを解放する。 |
| 2 | マイク停止・録音ファイル確定を認識終了待ちより先に実行。録音中の停止ボタンを認識の準備状態で無効化しない。 |
| 3 | 音声セッションの録音所有権と再生開始をロックで調停。録音中の再生をサービス・画面の両方で禁止し、理由を表示する。 |
| 4 / A | モデル読み込みから全チャンク終了まで利用権を保持。同一モデルの待機要求は既存ロードを再利用。context生成・参照・差し替え・解放を同じ直列キューに閉じ込める。 |
| 5 | ライブ認識の開始・停止・通知を操作世代に紐付ける。モデル準備待ちを含む古い開始処理が、新しいハンドラーを設定・削除しない。 |
| 6 | ダウンロードの進捗・保存・エラー通知を現在のタスクと照合。Core ML展開は操作固有の一時パスで行い、所有権確認後に確定する。 |
| 7 | 再認識中は編集を禁止。本文・セグメントの開始時リビジョンも比較し、変更・削除済みなら明示的な競合エラーにして保存済み編集を保持する。 |
| 8 | 起動時に専用Spotlight索引を削除してDBの現存レコードから再構築。DBが空の場合も古い索引を消す。索引操作は順序を保って実行する。 |
| 9 | HTTP成功とVADの配布元Git LFS SHA-256・885,098バイトを検証し、原子的に保存。起動時にも検証する。 |
| 10 | Speech資産の状態再確認・準備失敗・一覧更新で世代を確認し、旧言語の応答を破棄する。 |

## 検証

`ReviewRegressionTests.swift` に、同時ロード、キャンセル、モデル利用権、コールバック解放、録音と認識の停止順序、古いライブ開始・ダウンロード通知、索引削除失敗後の再起動相当、手修正競合、言語引数、モデル管理、変換波形、入力滞留上限などの回帰テストを追加した。

`SpeechAssetCoordinatorTests.swift` に、旧言語の応答を遅延させて新しい言語を開始した後に旧処理を再開するテストを追加した。

XcodeGenでプロジェクトを再生成。Xcode 27.0（27A5194q）で以下を確認した。

- iOS 27シミュレーターの単体テスト: 189件成功、失敗0件。
- 最大アクセシビリティ文字サイズを含むUIテスト: 3件成功、失敗0件。
- 最後のCore ML一時保存先調整後の関連テスト: 27件成功、失敗0件。
- iOS実機向けビルド: 成功（署名なし。実機実行を意味しない）。
- 既存10,000セグメント＋新規10,000セグメントの結合テスト: シミュレーターで平均約0.003秒。
- 動画経路で使用する変換処理について、44.1/48 kHzの連続入力と1,024フレーム分割入力を比較。出力フレーム数32,000で一致し、最大サンプル差は0.00001未満。

テストは通常のXcodeスキーム `WhisperTranscriptionApp` から再実行できる。新規回帰テストは `ReviewRegressionTests`、非同期の言語切替テストは `SpeechAssetCoordinatorTests.swift` にある。
