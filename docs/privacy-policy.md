# プライバシーポリシー

最終更新日: 2026年9月23日

本ポリシーは、iOS アプリ「Whisper文字起こし」（以下「本アプリ」）における個人情報の取り扱いについて説明します。本ポリシーは**法的助言を構成せず**、利用者の法令遵守義務（録音への同意等）を免除するものではありません。サービス全体の免責は [免責事項](disclaimer.html) を参照してください。

## 収集するデータ

文字起こし処理は端末内で行います。iCloud履歴同期をオンにした場合、以下の履歴データを利用者のApple AccountのiCloudプライベートデータベースへ送信します。初期設定では同期はオフです。

| データ | 用途 | 保存場所 |
|--------|------|----------|
| マイクで録音した音声 | 文字起こし・任意の履歴同期 | 端末内。同期オンの場合はiCloudにも保存 |
| インポートした音声・動画ファイル | 文字起こし・任意の履歴同期 | 処理は端末内。保存した音声は同期オンの場合にiCloudへ送信 |
| 文字起こし結果、タイトル、タグ、お気に入り、チャット内容 | 履歴表示・任意の同期 | 端末内（SwiftData）。同期オンの場合はiCloudにも保存 |
| アプリ設定（言語、モデルサイズなど） | 機能の提供 | 端末内（UserDefaults） |

## ネットワーク通信

- **初回およびモデル更新時**: Whisper / VAD モデルファイルを [Hugging Face](https://huggingface.co/) から HTTPS でダウンロードします。ダウンロード時に Hugging Face 側のログが記録される可能性がありますが、本アプリは音声や文字起こし結果を送信しません。
- **文字起こし処理**: モデル取得後はオフラインで実行され、推論データは端末外に送信されません。
- **iCloud履歴同期（任意）**: 同期をオンにした場合、履歴と録音音声をAppleのCloudKitへ送信し、同じApple Accountの端末間で同期します。通信設定は端末ごとにWi-Fiのみ、またはモバイル通信も許可から選べます。手動再生用の音声取得は、サイズ確認後に1件だけモバイル通信を許可できます。

## 追跡・広告

- 本アプリに広告は含まれません
- 第三者によるトラッキング（App Tracking Transparency 対象）は行いません
- 分析 SDK は使用しません

## データの共有

本アプリは、ユーザーの音声・文字起こし結果を開発者のサーバーへ送信しません。利用者がiCloud同期をオンにした場合はAppleのCloudKitに保存します。共有シートを使う場合は利用者が選んだ共有先へ送られます。

## データの削除

- 履歴: 削除後30日間は「最近削除した項目」から復元できます。iCloudに同期していない履歴は30日経過後、次回のアプリ起動・復帰時に端末から完全削除します。同期済みの履歴と音声は次回のiCloud同期時に完全削除します
- 録音ファイル: 同期済み音声は設定した日数の経過後に端末内コピーを取り除けます。iCloud上の音声は履歴の削除まで残ります
- モデルファイル: 設定からモデルを削除できます
- 同期オフ: 同期済みデータは端末内とiCloud上に残り、削除済み履歴のiCloud側の完全削除は同期を再開した次回の同期時に行います
- アプリ削除: 端末内の関連データは削除されますが、iCloud上のデータは残る場合があります
